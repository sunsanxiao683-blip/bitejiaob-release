# 注册工具 · 官方下载

本仓库**只放打包好的客户端程序**，不包含任何源码。

> 源码在私有仓库里，这里仅仅是**分发渠道**。

## 下载

去 [Releases](../../releases) 页面下载最新版本。

| 平台 | 架构 | 文件 | 说明 |
|---|---|---|---|
| Windows | x86-64 | `bitejiaob-win-*.zip` | 解压后双击 `注册工具.exe` |
| macOS | Apple Silicon (arm64) | `bitejiaob-macos-arm64-*.zip` | 解压后得到 `注册工具-macos-arm64.app` |
| macOS | Intel (x86_64) | `bitejiaob-macos-intel-*.zip` | 解压后得到 `注册工具-macos-intel.app` |

## 使用

1. 解压对应平台的 zip
2. **Windows**：双击 `注册工具.exe`
   **macOS**：双击 `注册工具-macos-*.app`
   （首次可能提示「无法验证开发者」→ 右键点它 → 选「打开」→ 再点一次「打开」）
3. 浏览器会自动打开控制台，按提示**登录**（账号密码由管理员下发）
4. macOS 用户还需安装 **AliasMode.app** 到 `/Applications`

## ⚠️ 注意事项

- 程序**必须联网**才能使用（激活 / 登录 / 心跳都走服务器）
- **一台电脑绑定一个账号**，换电脑需管理员在后台解绑
- 管理员停用账号后，程序会在 **30 秒内自动锁定并退出**
- 代理服务（`proxy.awser.store`）偶发 522，属于上游服务波动，与本程序无关

## ❓ 遇到问题

- **提示「设备不匹配」**：这台电脑已绑定了另一个账号，需管理员在后台解绑
- **提示「租约已过期」**：心跳失败，检查网络是否能访问授权服务器
- **macOS 提示「无法验证开发者」**：右键 → 打开 → 再点打开（见上文步骤 2）
- **提示「代理获取失败」**：上游代理服务波动，可稍后重试
